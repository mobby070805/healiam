# Premium Homepage Design Prompt: Internal SOP

## Purpose

The homepage prompt must produce a specific website design, not a generic AI-generated landing page.

Before writing the prompt, understand:

* Business
* Target customer
* Services
* Main USP
* Location
* Conversion goal
* Competitors
* Reference websites

The prompt must contain the actual business information.

## Mandatory Technical Requirements

Every homepage development prompt should include:

* Next.js
* TypeScript
* React
* Lucide React icons only
* Responsive design
* Mobile-first considerations
* Production-quality components
* Clean component structure
* Fast-loading implementation
* SEO-friendly HTML structure

## Mandatory Design Requirements

The website must feel:

* Premium
* Modern
* Trustworthy
* Professional
* Easy to understand
* Conversion-focused

Avoid generic AI website patterns.
Do not create sections simply to make the page longer.
Every section must have a purpose.

## Homepage Prompt Template

Use the following as the base prompt and customize the business-specific sections:

Create a premium, production-quality website for:

* Business: [BUSINESS NAME]
* Industry: [INDUSTRY]
* Location: [LOCATION]
* Primary services: [SERVICES]
* Target customers: [TARGET CUSTOMERS]
* Main USP: [USP]
* Primary CTA: [CALL / WHATSAPP / GET QUOTE / BOOK NOW]

The website must be built using Next.js + TypeScript.
Use Lucide React icons only throughout the website.
Do not use Font Awesome, emoji icons, random SVG icon sets, or inconsistent icon libraries.

### Design Direction

Create a premium, modern and trustworthy design appropriate for a real established business.
Do not create a generic AI landing page.
The design should feel intentionally designed for this specific business and its customers.
Use clear visual hierarchy, strong typography, appropriate whitespace and professional spacing.
Use a consistent, well-known font family throughout the entire website.
Do not mix multiple unrelated font families.

### Hero Section

The hero section must communicate the following within one glance:

1. What the company does
2. Who it serves
3. Why customers should consider the company
4. What action the visitor should take

Include a strong headline, concise supporting text and a clear CTA.
The primary CTA should be visually prominent but should NOT occupy the entire screen.
Use appropriate supporting imagery where it improves understanding.
Do not use decorative images simply for the sake of filling space.

### Homepage Sections

Build sections based on the actual business.
Recommended structure:

* Hero
* Trust / credibility indicators
* Why Choose [Company]
* Core Services
* How It Works
* Industry/use-case section where relevant
* Reviews / testimonials
* Pricing or quote CTA where applicable
* FAQs
* Location / Google Business Profile section
* Final CTA
* Footer

Do not blindly use every section.
If a section does not provide useful information or improve conversion, remove it.

### Content Layout

Important information should be understandable without excessive scrolling.
Some sections should present multiple pieces of information within a single viewport where appropriate.
Avoid extremely long text blocks.
Use:

* Cards
* Grids
* Short paragraphs
* Visual hierarchy
* Icons
* Relevant images
* Clear CTA placement

### Mobile Design

Mobile responsiveness is extremely important.
Design for:

* 375px
* 390px
* 430px
* Tablet
* Desktop

The mobile experience must be intentionally designed rather than simply shrinking the desktop version.
Check:

* Navigation
* Hero
* Buttons
* Forms
* Cards
* Images
* Typography
* Section spacing
* Horizontal overflow
* CTA placement

No element should overflow horizontally.
Buttons must be easy to tap.
Text must remain readable without zooming.

### CTA Design

CTAs should be clear and appropriately positioned.
Possible CTAs:

* Call Now
* WhatsApp
* Get a Quote
* Book a Consultation
* Contact Us
* Request Service

Do not create oversized CTA blocks that unnecessarily dominate the viewport.

### Images

Use images only when they support the section's purpose.
Images should:

* Match the business
* Be appropriately cropped
* Have correct aspect ratios
* Load efficiently
* Not break the layout on mobile
* Support the user's understanding of the service

### Icons

Use Lucide React icons consistently.
Choose icons that clearly represent the content.
Do not use icons merely as decoration.

### Quality Standard

The final website should look like a professionally designed commercial website, not an AI-generated template.
Prioritize:

* Clarity
* Trust
* Conversion
* Mobile usability
* Performance
* Visual consistency
* Brand relevance

Before completing the homepage, review the entire page at mobile and desktop widths and remove anything that feels generic, repetitive or unnecessary.

## Final Review

Before approving the homepage:

* Business is immediately understandable
* USP is clear
* CTA is visible
* Design is not generic
* Mobile layout works at 375px
* No horizontal overflow
* Images are relevant
* Lucide icons only
* One consistent font family
* Sections are not unnecessarily long
* Content is easy to scan
* CTA does not dominate the screen
* Homepage matches the approved design
* Senior/team design review completed
